# 审查覆盖面补齐计划

## P0：大纲审查（地基）
- 阶段：outline_writing 后强制执行
- Agent：continuity-reviewer + character-world-reviewer + commercial-editor
- 审查维度：Bible完整性、伏笔设计、人物设定完整性、盈利适配、平台合规
- 门禁：二进制≥90通过，<90不通过

## P0：细纲审查（施工图）
- 阶段：chapter_outline 后强制执行
- Agent：continuity-reviewer + commercial-editor + engagement-reviewer
- 审查维度：与大纲一致性、平台算法适配、付费卡点、钩子强度
- 门禁：二进制≥90通过

## P1：市场决策审查（平台+题材）
- 阶段：genre_selection 后
- Agent：commercial-editor
- 审查维度：WebSearch数据可靠性、推荐理由充分性

## P1：创作规划审查
- 阶段：creation_planning 后
- Agent：commercial-editor
- 审查维度：存稿计算、更新频率可行性、收益预估合理性

## P2：作品确认审查
- 阶段：novel_confirmation 后
- Agent：commercial-editor + engagement-reviewer
- 审查维度：书名辨识度、简介吸引力、概念差异化

## P2：发布+变现审查
- 阶段：launch_strategy + monetization_strategy 后
- Agent：commercial-editor
- 审查维度：存稿一致性、付费设计合理性
