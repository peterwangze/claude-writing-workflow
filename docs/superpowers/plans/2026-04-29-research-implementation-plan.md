## P0：缺失约束（7项 — 描述已存在但缺硬门禁）

### P0-1：CCC三要素硬阻断
- 文件：`quality-review/SKILL.md` + `using-writing-workflow/SKILL.md`
- 机制：前3章生成后，Contract-Clock-Crucible任一缺失 → F4阻断
- 数据：番茄前200字无钩子=80%划走

### P0-2：章节字数偏差约束
- 文件：`content-generation/SKILL.md` + `quality-review/SKILL.md`
- 机制：看护包新增字数目标字段，质量审查F3门禁检查偏差 > ±20%

### P0-3：回报频率硬门禁
- 文件：`chapter-outline/SKILL.md` + `quality-review/SKILL.md`
- 机制：连续10章无中回报 → F4阻断。连续性账本跟踪回报密度

### P0-4：情感签名履约
- 文件：`creation-planning/SKILL.md` → `quality-review/SKILL.md`
- 机制：情感签名写入workflow-state，质量审查检查连续5章偏离 → F3警告

### P0-5：钩子交付验证
- 文件：`content-generation/SKILL.md` + `quality-review/SKILL.md`
- 机制：看护包记录细纲承诺的钩子强度，质量审查对比正文实际交付

### P0-6：平台规则约束化
- 文件：`content-generation/SKILL.md`
- 机制：看护包新增"平台规则约束"区块，质量审查F3门禁检查合规

### P0-7：累积偏离度追踪
- 文件：`quality-review/SKILL.md` + `continuity-ledger.md`
- 机制：滚动10章累积偏离度 > 10% = 警告，> 15% = F4阻断
