- 8万字进入验证期 → 10万字开启首秀

### 二、起点中文网

#### 签约政策

| 项目 | 详情 |
|------|------|
| **签约门槛** | 通常需达到 **3万字以上** + 一定追读/收藏量，作家助手内才会出现"申请签约"入口 |
| **两条路径** | **直发**（默认路径）：发3章≥6000字 → 系统交叉审核 → 达标后申请签约；**内投**（精准投稿）：准备6000字正文+大纲+人设 → 锁定编辑邮箱投递 |
| **审核周期** | 直发5-10个工作日；内投72小时未回复可换编辑 |
| **年龄要求** | 未满18周岁无法签约（可先创作积累） |
| **核心隐形条件** | 每日4000字稳定更新；新书期前7天数据至关重要 |
| **关键建议** | 大纲比已更新字数更能说服编辑——签约审核时清晰的大纲是决定性因素 |

## 综合推荐

### 推荐平台排序（针对长篇小说50万字+、盈利导向）

#### 1. 起点中文网（首选推荐）★★★★★

**推荐理由**：

- **付费订阅生态最适合长篇**：长篇小说的核心盈利模式是持续订阅收入，起点拥有全网最成熟的付费阅读体系。订阅分成（50%）+ 全勤奖（600-1500元/月）+ 半年奖（订阅收入40%加成）为长篇连载提供阶梯式收入增长路径。
- **50万字保底奖励体系**：签约后50万字以上最少可获5000元保底奖励，为长篇创作的"无人区阶段"提供经济保障。
- **IP价值天花板最高**：影视/动漫/游戏改编通道最成熟，长篇是IP改编的核心供给源（2025年IP改编市场规模达3676亿元）。
- **长尾收益最优**：完结后存量付费订阅可持续产生收入，长篇完本作品两年后仍可有收入。
- **AI政策平衡**：阅文官方提供AI辅助工具（WriteClaw），鼓励辅助但打击替代，政策在创新与合规间取得较好平衡。

**风险警示**：
- 签约门槛高，需数据表现+编辑认可
- 900万注册作者中90%月入低于5000元，头部效应极为显著
- 2026年初推荐机制改革经历剧烈震荡，平台规则不确定性较高
- 新书期前7天数据至关重要，前期需快速积累追读
- ⚠️ 不适合"赚快钱"心态——起点是一个需要6-12个月持续投入才能看到回报的平台

#### 2. 七猫小说（稳健之选）★★★★☆

**推荐理由**：

- **保底机制提供收入下限**：在四平台中收入确定性最高。新人训练营千字10元奖学金 + 保底签约千字20元起，为长篇创作的漫长周期提供经济缓冲。
- **新人训练营极度友好**：零门槛入场，前两个月无更新要求，编辑一对一指导，适合零经验新人。
- **长篇友好**：只要作品被阅读就有收益，无过期概念，完结后仍可持续产生被动收入。
- **短剧改编新红利**：2026年短剧定制文保底3-10万/部，为长篇写作者提供额外变现渠道。

**风险警示**：
- 签约后版权归平台所有，作者仅保留署名权和收益权
- 新人训练营有毕业考核，并非所有人都能升级保底
- 保底期（通常3-6个月）后转为纯分成，收入可能大幅下降
- 合同中可能包含单方面终止保底的条款——请仔细审查合同
- 小众题材较难获得流量倾斜，题材选择受限
- ⚠️ 长篇IP衍生收益有限——如果目标是影视/动漫改编，七猫不是最优选

#### 3. 番茄小说（快速验证）★★★☆☆

**推荐理由**：

- **签约门槛最低**：2万字即可申请，三次签约机会降低试错成本，适合快速验证市场。
- **流量池最大**：2.45亿MAU，理论上曝光机会最多。
- **全勤奖直接**：600-800元/月全勤奖为日常更新提供基础收入。
- **短剧改编有扶持**：爆款原著最高奖300万元/部。

**风险警示**：
- 🔴 **极度红海**：60万签约作者，日上新书数千本，AI文泛滥挤压真人作者流量
- 🔴 **长篇慢热作品极难生存**：算法只认"强情绪、快节奏爽文"，慢热铺垫基本无流量——长篇小说的天然节奏与番茄算法逻辑存在根本性冲突
- 🔴 **首秀即扑街成常态**：新书验证期流量严重不足，"10万字前单机期"考验耐心
- 🔴 **收入极不稳定**：首秀期可能日收数百，后续或降至每日几十元；仅1.56%作者月入超2500元
- ⚠️ **版权归平台**：签约后版权归番茄所有

#### 4. 晋江文学城（女频专属）★★★☆☆（仅限女性向作品）

**推荐理由**：

- **女频IP改编第一平台**：影视化率最高，《陈情令》《天官赐福》等顶级IP源头
- **版权分成最优**：作者版权分成70%-80%（出版）至80%（头部影视），显著高于其他平台
- **签书不签人**：仅作品签约，作者保持高度自由
- **读者粘性极强**：高消费能力的一二线城市年轻女性读者，日平均在线时长75.2分钟

**风险警示**：
- 🔴 **不适用于男性向作品**：用户93%为女性，男性向长篇无市场
- 🔴 **AI政策行业最严**：仅允许校对/起名/粗纲级别的AI辅助，禁止AI润色文字和生成细纲——如果你的创作流程依赖AI辅助，晋江不适合
- 🔴 **签约门槛极高**：编辑审美主导，对文字质量、人设构建要求较高
- ⚠️ **不适合追求更新速度的作者**：晋江读者重视质量而非速度

## 合同陷阱避坑提醒

在签约前，请特别关注以下关键条款：

1. **版权归属**：番茄和七猫签约后版权归平台所有；起点和晋江作者保留较多版权权益
2. **独家授权范围**：确认是否为"独家"、地域范围、权利范围——避免"全球永久独家全部版权"条款
3. **自动续约**：检查是否有自动续约条款，建议改为双向确认机制
4. **未来作品**：警惕"未来作品优先购买权"条款，如无法删除则严格限定范围和期限
5. **竞业限制**：检查是否有竞业限制条款，如无法删除则要求支付竞业补偿金
6. **解约条件**：确保包含明确的解约条款（如平台拖欠稿酬超过X天、作品连续X月无收益等）
7. **保底终止条款**：七猫保底签约需特别注意平台单方面终止保底的条款

> ⚠️ 以上合同条款示例为通用风险模板，具体条款因平台和个人合约而异。签约前强烈建议咨询专业人士或律师。
