# 第1章 正文看护卡

## 本章输入状态
- 承接上一章的事件：无（首章，故事起点）
- 主角当前目标：完成本周最后一个加班任务——对一具从老城区拆迁现场送来的无名骸骨进行常规法医检验
- 关键人物状态（来自 story-bible 人物基线）：
  - 宋辞：26岁，江城公安局法医室合同工（非在编），阴脉体质（尚未觉醒），无修为，无修真认知。当晚独自加班。性格冷静、理性、较真。左手腕有3cm旧疤（大二被骨碎片划伤）
  - 老马（马德胜）：60岁，殡仪馆工人，负责遗体搬运。在殡仪馆工作40年，隐约知道"法医室不对劲"但从不多问
  - 沈归澜：66岁，退休返聘法医顾问，阴律司正统传人，筑基后期。**本章不出场**
  - 赵冬铭：32岁，刑警副队长，纯粹凡人。**本章不出场**
  - 周小卉：25岁，法医技术员。**本章不出场**
- 当前关系状态：
  - 宋辞-老马：日常的工作交接关系，有默契但不亲密
  - 宋辞-沈归澜：尚未建立师徒关系（沈归澜已知宋辞的阴脉体质但在等待时机）
- 时间与地点锁定：周五深夜 22:50 起 / 江城公安局法医中心（城郊结合部，一栋不起眼的四层灰色建筑）

## 本章必写场景
1. **深夜送骨**：老马将无名骸骨送至解剖室，交接过程中给出第一个异常暗示（"骨头比正常重"）
2. **骨骼的沉默**：宋辞按标准流程进行法医骨骼检验，展示完整的法医专业操作，并在检验过程中发现三处异常（骨小梁排列异常、骨密度异常偏高、骨髓腔内壁金色光泽残留物）
3. **遗识——死者的最后三分钟**：宋辞在触碰颅骨左侧蝶骨区域时被动触发遗识，接收死者死前最后3分钟的碎片化画面——月色小巷中被追杀的片段
4. **理性与本能的拉扯**：画面结束后宋辞的自我审视——用法医的理性逻辑说服自己"这是疲劳导致的幻觉"，但内心的不安已经开始松动

## 本章禁止偏离项
- 不得跳过"三处骨骼异常"的递进发现（骨小梁→骨密度→金色粉末）——它们是遗识触发前必须构建的"科学层面的好奇"
- 不得让遗识画面过于清晰完整（硬事实3：遗识是主观记忆，不是客观录像）——画面必须是碎片化、摇晃、不连贯的，尤其不能出现高清的面部特写或清晰的人物对话
- 不得让宋辞在章末"相信"遗识的真实性——他必须用理性将之解释为幻觉（这是第1-5章"怀疑→确认"弧线的第一部分）
- 不得无铺垫引入任何修真术语（"灵骨"、"遗识"、"阴律司"、"灵气"等词汇在本章正文中一概不出现——只有读者从异常中自行猜测）
- 不得让沈归澜在本章出场（哪怕只是"在走廊里擦肩而过"）——根据大纲时间线锚点，沈归澜在第6-10章才正式登场

## 本章允许发挥范围
- 可补充的细节方向：解剖室的环境描写（无影灯的冷光、不锈钢台面的反光、冷冻柜的嗡鸣）、江城夜景的氛围渲染（窗外的万家灯火 vs 解剖室内的冷寂）
- 可扩写的情绪段落：宋辞独自面对骸骨时的内心独白（"又是一个没人认领的"——法医对无名尸体的职业性怜悯）、接触到异常时的心跳加速和手汗细节
- 可增加的环境描写：法医中心的建筑外观、走廊的声控灯、电梯旁的排班表（展示宋辞的合同工身份）

## 本章必须回收/推进
- 无回收项（首章）。本章须**埋设**以下伏笔：
  - F-001：无名骸骨的真实身份——通过骨龄、骨密度异常、金色粉末暗示其为明代阴律司成员
  - 宋辞手腕旧伤：戴手套时露出的3cm疤痕（F-012的最早暗示）
  - 金色粉末在常态环境中的逸散速度（灵气衰减规律的第一个实例）

## 本章结束状态
- 章节结尾人物位置：宋辞走出法医中心大楼，准备回家。口袋里有那张金色粉末已黯淡的滤纸
- 章节结尾情绪状态：困惑+自我压抑——大脑的理性部分说服他"那是幻觉"，但身体的记忆（手指的发抖、指尖的寒意）拒绝接受这个结论
- 留给下一章的钩子：遗识画面中追兵穿的鞋——一双不该出现在明代石板路上的现代运动鞋。宋辞说服自己是幻觉，但他无法解释那个细节。（信息悬念：追兵是谁？为什么穿现代鞋？）
