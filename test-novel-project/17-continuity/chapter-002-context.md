# 第2章 正文看护卡

## 本章输入状态
- 承接上一章的事件：
  - 宋辞在解剖无名骸骨时触碰颅骨触发了一次约3分钟的不明视觉片段（遗识——但他尚未认知为"遗识"）
  - 遗骨的三处骨骼异常：骨小梁规则排列、骨密度异常偏高（2580-2820HU）、骨髓腔内壁有金色光泽残留物
  - 金色粉末在滤纸上从亮金色→灰白色，衰减时间约60±10秒
  - 宋辞在正式解剖报告中只写了"骨密度偏高"，将"异常视觉片段"排除在报告外
  - 他从解剖室出来，内心被"那个画面中的追兵穿着现代运动鞋"这个矛盾信息困扰
- 主角当前目标：重新检验无名骸骨，确认昨晚的"异常"是否有可重复的物理证据（目标来自第1章结尾宋辞的选择——"再查一遍"）
- 关键人物状态（来自第1章 ledger）：
  - 宋辞：疲惫但警觉——凌晨在解剖室长椅上度过，未回家。情绪状态从"自我说服"转向"需要进一步验证"。身体上：手指的寒意感已消退，但遗识画面的闪回仍在偶尔出现
  - 老马：已完成第1章的送骨任务，本章不出场
  - 周小卉：尚未亮相，本章场景一首次出场——周末早班，状态轻松
  - 赵冬铭：尚未亮相，本章场景三首次出场——周六加班，状态轻松（不穿正装）
  - 沈归澜：本章通过"电话无人接听"间接出场——读者首次听到这个名字
- 当前关系状态：
  - 宋辞-周小卉：法医室日常的师徒型工作关系（周小卉尊重宋辞的专业能力，宋辞对她有指导但不亲近）
  - 宋辞-赵冬铭：已建立的信任型办案搭档关系（赵冬铭信任宋辞的专业判断，宋辞依赖赵冬铭的刑警资源）——**本章首次在正文中展示**
  - 宋辞-沈归澜：尚未建立关系，但宋辞知道沈归澜是退休返聘顾问（关系铺垫）
- 时间与地点锁定：周六凌晨至下午 / 法医中心（主要地点）；第1章结束时间为周五凌晨1:00，第2章开始时间为周六早晨7:30

## 本章必写场景
1. **法医室的早晨**：周小卉发现宋辞在解剖室长椅上过夜，两人简短互动，展现法医室日常生态和周小卉作为助手的定位
2. **黑色笔记本**：宋辞独自在解剖室重检遗骨，在私人笔记本上系统记录三处异常数据，并首次写下"不明原因的感知异常"——笔记本与正式报告之间出现了选择性记录的分歧
3. **搭档的来访**：赵冬铭来询问无名骸骨的初步结果，提供案件来源的详细信息（拆迁现场#12号建筑地基下方、俯卧埋葬、青砖坑+石板、施工队发动机熄火异常）
4. **月光中的运动鞋**：宋辞独自复盘遗识画面的更多细节，通过逐元素提取法医式分析，得出"追兵不是古人"的关键推论。随后进行CT扫描，在颅骨中发现灵气结晶（CT值高达4200HU的椭圆形高密度结构），章末拨打沈归澜电话——无人接听

## 本章禁止偏离项
- 不得让宋辞在正式报告中写出"不明感知异常"或其他明确指向超凡的措辞——他的职业谨慎要求在未确证前不将不确定信息写入正式文件（性格基线：较真但对形式有分寸）
- 不得让赵冬铭追问宋辞的"异常状态"超出合理范围——他问了"你脸色不好""是不是又通宵了"，然后就不再追问。赵冬铭的"不问"是信任，不是迟钝（凡人配角基线）
- 不得让宋辞在章末与沈归澜的实际对话——沈归澜在第2章只能通过"电话无人接听"间接登场（大纲：沈归澜在第6-10章才正式出场）
- 不得将遗识画面中的"运动鞋"线索写成确定的品牌型号——宋辞只能说"鞋型很像"，不能直接认出是"某品牌限量款"（保留后续验证的空间）
- 不得在CT扫描时出现"灵气""灵骨""遗识"等修真术语——所有描写必须停留在法医/医学的表述框架内（"CT值异常""高密度椭圆形结构""光晕伪影"）
