# 第2章：黑色笔记本

## 基本信息
- 所属卷：第一卷《遗识初现》
- 字数目标：2500-2800字
- 预计爽点：推理快感（异常线索的整理）+ 法医室人际生态

## 章节概要

宋辞在解剖室的长椅上度过了一个无眠的凌晨。天亮后，法医技术员周小卉来上班，发现宋辞脸色不对。宋辞将昨晚的"异常观察"记录在一本私人笔记本上——不是官方解剖报告（他只在正式报告中写了"骨密度偏高"），笔记本中详细画出了三次异常的位置、数据、以及——他犹豫后还是写下的一行字："触碰颅骨时出现不明原因的感知异常"。刑警副队长赵冬铭上午来法医室询问无名骸骨的初步结果，宋辞只给出了正式报告中的信息，没有提遗识的事。赵冬铭告知案件来源：老城区汉阳片区的拆迁工程，施工队在拆除一栋民国建筑时挖出了埋在地基下方约三米深的骸骨。宋辞在赵冬铭离开后，独自复盘了遗识画面的更多细节——这一次，他记下了画面中每一个能回忆起来的元素，包括那个追兵身上一个不该出现在明代街头的细节：脚上的鞋。

## 详细情节

### 场景一：法医室的早晨
- 地点：法医中心，解剖室+办公室
- 时间：周六上午7:30-9:00
- 出场人物：宋辞、周小卉
- 情节内容：
  晨光透过解剖室唯一的窗户照进来——那是一扇位于墙壁高处的狭长窗户，光只能斜斜地打在地面上，解剖台永远在阴影中。宋辞从解剖室角落的长椅上坐起来，身上的白大褂皱成一团。他没回家——昨晚从解剖室出去后，走到停车场，在车里坐了十分钟，又走回来了。他需要再确认一次。

  周小卉刷卡推开法医室的门，被长椅上的宋辞吓了一跳。"宋哥？你昨晚没回去？"宋辞含糊应了一声，去洗手间用冷水洗了把脸。镜子里的人脸色发白，眼眶下有明显的阴影，但他的眼神比平时更锐利——这是法医的职业本能：当你发现了一个无法解释的现象，你的第一反应是"再查一遍"。

  周小卉给宋辞倒了杯热水（法医室唯一的"人情味"——技术员对主检法医的日常照顾），同时汇报了当天的待办事项：两例常规交通事故尸检、一例养老院自然死亡确认。宋辞让她先做常规的，自己则需要"重检昨天那具骸骨"。

  **场景功能**：①引入周小卉——展现法医室的"日常生态"和她作为助手的定位 ②通过周小卉的眼睛展示宋辞的状态（"脸色不对"）——建立"读者知道宋辞经历了什么，但周小卉不知道"的信息不对称张力 ③"再查一遍"这个行为本身就是宋辞性格"较真"的呈现

### 场景二：黑色笔记本
- 地点：解剖室
- 时间：周六上午9:15-10:45
- 出场人物：宋辞（独自）
- 情节内容：
  宋辞从冷冻柜取出那具无名骸骨。在无影灯下重新排列骨骼——这一次不是按标准检验流程，而是按他昨晚观察到异常的顺序：颅骨（骨小梁异常）→股骨（骨密度异常）→肋骨断面（金色光泽残留物）。

  他从白大褂口袋里掏出一本黑色封面的笔记本——不是法医室的正式记录本，而是他自己的私人笔记。封皮已经磨损，内页写满了他经手的每一个"不太对"的案件（不是每个案件都有问题，但他养成了习惯：记录所有暂时无法解释的细节）。

  **笔记本内容展示**（本章的重点沉浸段落，展现宋辞的"法医式思维"——严谨、系统、不放过任何细节）：
  - 第一页：无名骸骨的简易素描（他画了一幅骸骨的正面/侧面/背面三视图，笔触简洁但比例精准）
  - 翻到新一页，他写下日期和案件编号，然后列出异常观察：
    ```
    ①颅骨骨小梁排列异常：规则几何图案（疑似菱形网格）——需对照骨组织病理学图谱确认
    ②股骨骨密度：2580-2820HU（三次测量均值约2700HU）——超过已知任何骨硬化病理上限
    ③肋骨断面腔内金色粉末：刮取量约0.3mg——置于滤纸上，30秒内光泽由亮金色→灰白色
    ```
  - 在第三条下方，他停下笔。笔尖悬在纸面上方三毫米，停了大约十秒。然后他写下：
    ```
    ④触碰颅骨左侧蝶骨区域时发生不明原因的感知异常：出现持续约3分钟的视觉片段——内容为月色小巷中一人被追杀的片段。不确定性质。待确认。
    ```

  **沉浸点设计**：这整段的描写节奏刻意放缓，让读者跟随宋辞的笔尖，一起进入他的推理思维。每一个数据都是精确的，每一个措辞都是谨慎的（"不明原因的感知异常""待确认""疑似"），呈现法医的职业惯性——在证据不充分时不下结论、但也不忽略异常。

  他合上笔记本，塞回口袋。然后打开电脑上的正式解剖报告系统，在"异常发现"一栏里只写了一行字：**"骨骼密度高于正常值，无外伤痕迹，建议进一步检验。"**

  笔记本和正式报告之间隔着三条异常——这是一个微妙的伏笔：宋辞开始"选择性地记录"，这种选择是出于法医的谨慎（没确证的东西不进正式报告），但也暗示了他已经开始认真对待"那不是什么幻觉"的可能性。

### 场景三：搭档的来访
- 地点：法医中心办公室
- 时间：周六上午11:00-11:30
- 出场人物：宋辞、赵冬铭
- 情节内容：
  赵冬铭推开法医室的门，手里拎着两杯咖啡。他今天没有穿那套不合身的便衣西装，而是穿着一件深蓝色Polo衫——周六加班，不用应付领导，他放松了一些。"宋辞，昨晚送来的那具骨头怎么样？施工队那边在催——他们说挖出人骨不吉利，想快点搞清楚是不是刑事案件，好决定要不要报警。"（这是个黑色幽默——施工队不知道他们已经"报警"了，因为尸骨已经在本市的法医中心了。赵冬铭说这话的时候表情介于好笑和无奈之间。）

  宋辞把打印好的初步报告递给赵冬铭。赵冬铭一边看一边皱眉头："骨龄约400年？那就不是刑事案了——明代的事，已经过追溯期了吧？"他把报告翻来覆去看了两遍，指着"骨骼密度异常"那一行问："这个是什么意思？是人骨的密度还是别的什么东西？"宋辞说："不确定。需要进一步检验。"

  赵冬铭问出了本章的关键信息——案件来源的详细情况：
  - **发现地点**：老城区汉阳片区棚户区改造工程的A3标段，原来是几排民国时期的二层木结构住宅，正在被拆除
  - **发现过程**：挖掘机在拆除一栋编号为#12的民国建筑的墙基时，在地下约三米深处挖出了一块刻着花纹的石板。抬起石板后，下面是一个用青砖砌成的约半米见方的坑，坑底就是这具骸骨。没有棺木、没有任何随葬品、骸骨呈俯卧状态（面朝下趴着）——不符合任何已知的明代葬俗
  - **施工队态度**：工头老陈说"这东西邪门"，因为挖掘机的挖斗在碰到石板的一瞬间，发动机熄火了三次。后来换了台推土机才把石板推开

  **人物互动设计**：这一段对话中，赵冬铭的"粗中有细"性格开始展现——他看报告时不是一扫而过，而是会抠细节（"这个骨密度是什么意思"），但他用咖啡和冷笑话来平衡自己的认真。宋辞在对话中保持专业但略有分神——他心里在比对赵冬铭说的"石板+青砖坑"和遗识画面中的"石板路+小巷"。这是第一个线索交叉点。

  赵冬铭走到门口时回头问了一句："你脸色不太好，昨晚是不是又通宵了？"宋辞说："没睡好。"赵冬铭看了他两秒，没追问，只说了句："周六早点回去。你又不是在编的，没人给你发加班费。"——这句话一方面是赵冬铭式的关心（务实、不煽情），另一方面再次暗示了宋辞的合同工身份。

### 场景四：月光中的运动鞋
- 地点：解剖室
- 时间：周六下午2:00-3:30
- 出场人物：宋辞（独自）
- 情节内容：
  宋辞第三次打开冷冻柜。这一次，他做了不同的事：他搬了把椅子坐在解剖台旁边，闭上眼睛，尝试回忆昨天那个画面的每一个细节。不是法医式的客观记录——是他自己的主观回放。他在笔记本上写下画面中的元素：

  - 月光（满月，月光颜色偏冷白——由此推断当晚天气晴朗无云）
  - 石板路（石板之间的缝隙长着青苔——由此推断这是一个潮湿的南方城市，与江城的纬度/气候吻合）
  - 两侧建筑（木结构，二层，门窗的雕花是明代风格——虽然是死者主观记忆，但建筑物的形制不太可能记错）
  - 死者的状态（俯卧/爬行姿势——与赵冬铭说的"骸骨呈俯卧状态"一致，这是第一个"遗识与现实吻合"的确认）
  - 追兵的轮廓（身高约175-180cm，偏瘦。步频不自然——步伐太快，但又不像是跑的动作，更像是一种比正常人快1.5倍的行走——"步频异常"是第二个宋辞无法解释的细节）
  - **追兵的鞋子**（关键元素）：月光打在地面上，有一瞬间照亮了追兵脚上的鞋。那不是布鞋、不是靴子——那是一双低帮运动鞋，鞋底很厚（可能是气垫底），鞋面有一个隐约的弧形logo（看不清，但宋辞见过的那个logo——上周在物证科走廊看到的那个证人，法警让他换鞋时脱下了一双限量的奈/阿迪跑鞋，鞋型几乎一样）

  宋辞在笔记本的这行字旁边画了一个感叹号。然后他写下："如果画面中的追兵穿着现代运动鞋，那么要么画面中有多个人（死者和另一个现代人），要么那个追兵不是一个'古人'。"

  这是一个法医的推理方式——不跳跃、不预设立场、只根据现有证据做最可能的推导。他合上笔记本，走到窗边。窗外的城市在阳光下运转如常，没有人知道这栋灰色建筑里的宋辞正在面对一个可能推翻他对现实世界全部认知的疑问。

## 伏笔/呼应

### 本章埋设
- **无名骸骨的埋葬方式**：俯卧、无棺木、砌在青砖坑中——这不是正常的葬礼，而是一种"镇压"或"封印"式的埋葬方式。这暗示死者不是因为自然原因被安葬，而是有人刻意将他埋在那个位置。这一细节将在后续章节（第91-95章阴律司遗址探索时）与遗址中的封印阵产生呼应
- **"发动机熄火三次"**：挖掘机碰到石板时的异常——这是灵气残余导致的电磁/机械干扰的第一次展示（后续将成为修真世界与现代机械互动的规则之一）
- **宋辞的选择性记录**：在笔记本上写"不明原因的感知异常"但在正式报告中只写"骨密度偏高"——这种"双重记录"的行为将成为宋辞在全书中的常态，也暗示了他"在体制内但不受体制完全约束"的处境

### 呼应前文
- 呼应第1章：①老马的"骨头太重"→本章宋辞在笔记本中补充了骨密度三次测量数据 ②"金色粉末从发光到黯淡"→本章宋辞在笔记本中用秒表重新记录了一次粉末的光泽衰减时间"约25秒" ③"遗识画面中的死前3分钟"→本章复盘时提取了更多细节（运动鞋、石板上的青苔、建筑的雕花）

## 章末钩子

- **钩子类型**：对话钩子 + 信息悬念
- **钩子内容**：下午四点半。宋辞把那具无名骸骨的颅骨放在托盘上，推进CT室。他需要一张高分辨率的头颅CT——不是为了法医报告（400年前的遗骨不需要CT），而是为了确认一件事：昨晚触碰颞骨时触发"画面"的那片区域，骨组织的密度和结构是否与颅骨其他区域存在物理性差异。CT扫描的嗡鸣声持续了二十秒。电脑屏幕上开始逐层显示颅骨的横截面图像——第1层正常，第2层正常，第3层正常——第7层。左侧蝶骨大翼区域的骨髓腔内，出现了一个CT值高达4200HU的致密结构——不是一个"点"，而是一个规则的、约2mm×3mm的椭圆形晶体。这个晶体在CT影像上呈现为一种他从未见过的颜色——不是因为密度，而是因为这颗晶体的边缘在CT图像中产生了一圈微弱的"光晕"（这是灵气结晶造成的CT伪影）。宋辞盯着屏幕上那粒发光的晶体，沉默了整整二十秒。然后他掏出手机，拨出了一个电话——不是赵冬铭。是法医中心的退休返聘顾问：沈归澜。电话响了五声。没有人接。
- **钩子强度**：强——三重复合悬念：①颅骨中的晶体是什么？②宋辞为什么打给沈归澜而不是赵冬铭？③沈归澜为什么不接电话？（读者在第1-2章尚未正式认识沈归澜，但他在此刻被引入——他是谁？他为什么是宋辞在这种情况下的第一个求助对象？）

## 注意事项

1. **宋辞打电话给沈归澜这个行为必须有铺垫**：在第1章-第2章的前半部分，通过极微小的暗示让读者知道沈归澜是退休返聘顾问（比如周小卉在Scene 1提到过"沈老师今天休息"、或者法医室墙上挂着的退休合影中有一个白发老人）。不能在第2章结尾突然冒出一个读者完全不知道的名字。
2. **"运动鞋"这个线索不能太明显**：宋辞只说"见过类似的鞋"，不能直接说"是某品牌的限量款"——这个信息应该在后续章节中通过物证科的线索确认。
3. **赵冬铭的戏份要平衡轻松和认真**：他是刑警副队长，办案时专业，但周六加班状态下的放松感也要体现。不能让他变成"只会问问题的工具人"。
4. **周小卉的场景时长短但必须有效**：她的出场时间不长，但需要通过动作和语气建立观众对她的认知——年轻、勤快、对宋辞有好感（不是感情线，是职场新人对技术型前辈的尊重），喜欢问问题但知道什么时候该闭嘴。
