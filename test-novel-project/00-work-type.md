# 作品类型信息

## 基本信息
- 作品类型：长篇小说（50万字以上）
- 确认时间：2026-04-29
- 目标平台：待定（进入平台调研阶段确定）

## 类型分析

### 市场背景（数据来源：中国社会科学院《2025中国网络文学发展研究报告》及多平台公开数据）

**市场规模**：
- 2025年网络文学阅读市场规模达502.1亿元，同比增长16.6%
- 作者规模达3269.4万人，较2024年新增149.6万人——竞争持续加剧
- 作品数量达4583.7万部，较2024年新增418.6万部
- IP改编市场规模爆发式增长至3676亿元，长篇作品是IP改编的核心供给源

**2026年新趋势**：
- 公众号小说小程序有望成为新赛道，可能造就第一批红利作者
- 番茄小说持续内卷，10万字前单机期考验耐心，20万字+10万阅读人数才有稳定收益
- 起点中文网签约门槛更高，但签约后的保底体系更完善（50万字以上最少可获5000元保底奖励）
- 短剧改编为长篇网文提供了新的版权变现渠道

### 特点
- 世界观宏大：适合构建完整的力量体系、势力格局和文明设定
- 连载周期长：通常需要6-12个月持续更新，对作者的时间管理和毅力要求高
- 读者粘性强：长篇能培养忠实读者群体，粘性远高于短篇
- 收入天花板高：完本后可享受长期的长尾收益（完结两年后仍可持续产生收入）
- IP改编潜力大：长篇是影视、动漫、游戏、短剧改编的主要来源
- 沉没成本高：如果中途放弃，前期的几十万字投入可能完全白费

|------|----------|----------|----------|

| 番茄小说 | 低（2万字后台申请，当天通过） | 广告分成 + 全勤600元 + 完本奖1000元 | 新人试水、追求快速验证 |

### 创作建议

1. **兼职起步，数据验证后再全职**：长篇小说的前10-20万字是"无人区"，建议保留主业收入，用业余时间完成前20万字积累和读者验证。如果20万字后数据有明显上升趋势，再考虑增加投入。

2. **存稿储备至少10万字再开更**：长篇连载最大的风险是断更。存稿10万字意味着即使连续三周没有创作状态，更新也不会中断。断更是长篇读者流失的第一大原因。

3. **50万字是盈亏分水岭**：多平台数据显示，长篇作品在50万字左右开始产生稳定的推荐流量和读者积累。在此之前，请做好"单机写作"的心理准备。

4. **题材选择要兼顾个人兴趣和市场热度**：2025年豆瓣/起点/番茄数据显示，玄幻、仙侠、都市、科幻为四大长青赛道；克苏鲁+东方修仙、年代重生+种田文等跨界融合题材正在上升。但核心是选自己最擅长的领域——长篇需要足够的热爱才能支撑到50万字。

5. **关注IP改编窗口**：短剧改编是2025-2026年长篇变现的新通路。写作时注意场景感和对话密度，有助于提升短剧改编价值。

### 盈利可行性初估（详细评估见04-creation-plan.md）

| 指标 | 估算 |
|------|------|
| 最低字数门槛 | 50万字 |
| 推荐完结字数 | 80万-150万字 |
| 预计耗时（兼职日更2000字） | 14-24个月 |
| 预计耗时（全职日更4000字） | 7-12个月 |
| 前20万字收入预期 | 极低（单机期，几乎无推荐） |
| 50万字后月收入区间 | 番茄：0-3000元 / 起点：0-5000元（取决于数据表现） |
| IP改编收入 | 不确定性极高，不作预期 |
| 盈亏平衡点 | 通常需要完结后3-6个月才能判断 |

> **坦诚提醒**：3269万作者中，真正实现月入过万的不足3%。长篇小说的盈利确定性高于短篇，但没有任何人能保证"写了就能赚钱"。请将第一部作品定位为"学习作品"——目标是完整地写完一部50万字以上的长篇，建立创作纪律和读者意识。盈利是第二部、第三部作品的事。

## 注意事项

- **风险提示**：长篇小说的最大风险不是"赚不到钱"，而是"写不完"。2025年数据显示，全平台长篇作品完本率不足15%。在开始之前，请认真评估自己是否能坚持6个月以上持续输出。
- **生活保障**：建议在开始长篇创作前，储备至少3个月的生活保障金。不要在生存压力下写作。
- **选平台不着急**：下一阶段将进行平台调研，基于你的题材偏好和创作习惯进行精准匹配。不要在选平台之前就开始写。
- **不要追求完美开头**：长篇的黄金法则是"先完成，再完美"。开头3万字反复修改是新人最常见的陷阱。
