# 主要人物设定

## 主角

### 基本信息
- **姓名**：宋辞
- **年龄**：26岁（故事开始时）
- **身份**：江城医科大学法医学硕士毕业，公考失败后进入江城公安局法医室担任合同工（非在编）
- **外貌**：身高178cm，体型偏瘦但手指有力（长期解剖训练的结果）。深棕色眼睛，习惯性微眯——不是近视，是职业习惯（法医需要仔细看）。常年穿白大褂，里面是灰色或深蓝色的基本款衬衫。左手腕有一道3cm的旧疤——大二实操课时被骨碎片划伤。头发总是比标准短发略长一点，因为他觉得去理发店浪费时间
- **出身**：普通工薪家庭，父亲是中学教师（已退休），母亲是社区医院护士（已退休）。无任何修真家族背景——他是阴律司遗识自行选择的"野生传人"

### 性格特点

**核心性格**：冷静、理性、较真——这是法医职业对性格的塑造。但冷静之下是强烈的正义感和对真相的偏执追求。

**性格层次**：
- **表层（职场面具）**：专业、寡言、不热衷于办公室政治。同事眼中的"那个技术好但不太合群的合同工"。面对尸体比面对活人更自在——他自己也清楚这一点，偶尔自嘲。
- **中层（私人空间）**：有自己的冷幽默（法医的黑色幽默），喜欢研究冷知识，独自一人时会在脑海中复盘案件的每一个细节。有不为人知的执拗——一旦认定的真相，绝不妥协。
- **深层（核心价值观）**：相信"死人不会撒谎"，相信"真相值得被看到"。他的正义感不是英雄主义——不觉得自己是救世主，只是觉得"如果我能看到真相而我不说出来，那我和帮凶有什么区别"。

**性格弱点**：
- **过度较真**：在小事上不懂得"差不多就行"，容易得罪人
- **情感表达缺失**：长期面对尸体，让他对活人的情绪感知有些迟钝。不是没有感情，是不会表达
- **信任门槛高**：法医的职业病——习惯性地对一切信息保持怀疑，很难完全信任他人（相信证据>相信人）
- **道德洁癖倾向**：对自己的道德要求很高，也会不自觉地用同样的标准要求他人。这在修真世界的灰色地带中会给他带来麻烦

**性格魅力点**：
- 在高压下保持冷静的专业素养（手术刀在手时绝不手抖）
- 用冷幽默化解紧张氛围
- 对弱者和死者的尊重是发自内心的，不是表演

### 背景故事

宋辞的父母是典型的"稳定压倒一切"的中国式家长。高考时，宋辞想报考古学（他从小对"从骨头里读故事"有莫名兴趣），被父母以"不好就业"为由否决。妥协结果是法医学——"至少是医学类，好找工作"。

大学期间，宋辞发现自己对法医学有真正的天赋和热爱。他尤其擅长骨骼检验——能在一堆碎骨中快速识别骨块所属的部位和受力情况。导师评价他"有一双为法医而生的手"。

毕业后，他连续两年公考失败（笔试能过，面试总是差一点——他的性格在面试中不占优势）。最终通过导师推荐，进入江城公安局法医室做合同工——工资是在编的60%，没有编制保障，随时可能不被续约。这是他选择接受"合同工"这个身份的第三年。

他不是英雄。他只是一个想把工作做好的人。

直到那一夜，那具从老城区拆迁现场挖出的无名骸骨被送进他的解剖室。

### 核心动机

- **表层动机**：做好法医的本职工作，查出每一具非正常死亡尸体的真相
- **中层动机**：遗识能力给了他一个"必须要用"的理由——他是万里挑一的阴脉体质，如果他不做，很多真相就会永远埋藏。这不是命运，是责任
- **深层动机**：对"真相"的信仰。宋辞内心深处相信一件事：如果真相可以被掩盖，那这个世界就没有规则可言。而一个没有规则的世界，活人和死人都没有尊严

### 金手指/特殊能力

**核心金手指：遗识读取**
- 万里挑一的"阴脉体质"——天生对阴气敏感，能感知遗骨中的灵力残留
- 通过解剖接触遗骨，读取死者刻在骨骼中的毕生修为记忆
- 金手指的"公平性"设计：遗识不能直接转化为修为（铁律5），只能提供修炼方法和战斗经验。宋辞还是要自己修炼，只是"知道怎么修"的效率远高于"自己摸索"

**次要优势：法医专业技能**
- 骨龄检测 → 判断修为年限（灵骨特征类似于凡人骨骼的年龄特征，但有灵气维度）
- 伤情分析 → 识别对手的旧伤/弱点
- 毒理分析 → 理解丹药成分
- 解剖学知识 → 精准打击灵气节点（穴位）
- 死亡时间推断 → 判断对手的灵气衰减速度（≈残余战力评估）

## 主要配角（关键配角）

### 1. 沈归澜 — 导师/阴律司引路人

- **身份**：江城公安局法医室退休主任，66岁，阴律司正统传人之一。退休后被返聘为"技术顾问"，实际上是为了在法医室守着阴律司的最后据点
- **与主角关系**：师徒——沈归澜是第一个发现宋辞"阴脉体质"的人，也是将宋辞引入修真世界和阴律司传承的引路人
- **性格**：老人精。表面是一个随和的退休老头，爱喝茶、爱下棋、爱跟年轻法医讲"当年的案子"。实际上是阴律司解体后少数保持着完整传承意识的人。他的"随和"是伪装——在涉及阴律司的事情上，他比任何人都严肃
- **外貌**：满头白发但精神矍铄，常年穿一件旧的深蓝色中山装（口袋里有永远吃不完的花生米）。右手食指有一道从指尖延伸到掌心的旧伤——年轻时在一次遗识读取中，遗骨的灵气结晶崩解时割伤了他
- **在故事中的作用**：
  - 第一卷：引导者——教宋辞理解遗识，传授阴律司的基础法门，提供修真世界的基础认知
  - 第二卷：导师——系统化宋辞的能力，讲述阴律司的历史，引荐其他阴律司残余传人
  - 第三卷：幕僚——退居二线，为宋辞提供建议但不再替他做决定。这是宋辞独立的标志
  - 第四卷：牺牲/重创——在某一关键节点为保护宋辞或阴律司传承而付出重大代价（可能的死亡或修为丧失），这是宋辞被彻底推向"主动破局"的关键转折
- **发展规划**：
  - 核心作用：作为"上一代阴律司"的代表，他承载着阴律司的历史和创伤
  - 核心创伤：200年前阴律司大分裂的亲历者后代——他的师祖是大分裂中的幸存者，留给他的是"不要再试图重建阴律司"的遗训。但他依然选择在法医室守着最后一点火种
  - 对主角的影响：沈归澜的牺牲/重创是主角从"被动卷入"到"主动承担"的转折点

### 2. 林妙然 — 女主/都市修真世界的另一个入口

- **身份**：28岁，表面上是一个独立的文物修复师（在江城博物馆工作），实际上是万剑盟外围情报网络的成员——她的文物修复工作让她能接触到大量古籍=修真功法残本。她的真实身份极其特殊：**万剑盟盟主的私生女**，在盟内地位尴尬，被安排在"外围"是某种形式的放逐+保护
- **与主角关系**：感情线女主（慢热型）。第一卷首次出场——一起涉及文物的案件让两人的职业产生交集。第二卷开始发展关系。第三-四卷进入深度关系。第五-六卷面临"万剑盟vs阴律司"的立场冲突
- **性格**：表面温润如水——文物修复师的职业气质。但实际上非常聪明、有主见、善于观察（修复文物的核心技能=从碎片中还原真相，这和宋辞从遗骨中读取遗识是两种不同路径的"真相还原"）。她的"温柔"是保护色，内心有从小在门派权力斗争中养成的警惕和敏锐
- **外貌**：身高165cm，黑长直发（工作时盘起），气质清雅。手指修长稳定（修复文物的手），手腕上常戴一串看似普通的檀木珠——实际是万剑盟的传讯法器。穿衣风格低调但有品味，不追求时尚但不经意间展露出高于工薪阶层的审美
- **在故事中的作用**：
  - 为宋辞提供修真世界从"万剑盟视角"的信息，与沈归澜的"阴律司视角"形成互补
  - 感情线提供情感温度和人性化维度——在冷硬的遗骨和案件之外，有一个人在等他
  - 第五-六卷的核心张力来源：当阴律司与万剑盟的利益冲突不可调和时，她必须在爱情和家族之间做出选择
- **发展规划**：
  - 第一卷：文物案件中的"线索提供者"，与宋辞初次接触。宋辞发现她的文物修复技能与遗识读取有某种"异曲同工"之处
  - 第二卷：关系升温。她主动向宋辞透露了自己的修真者身份——这是她对宋辞的信任，也是她在万剑盟中找不到归属感的映射
  - 第三卷：深度关系确立。她开始利用文物修复工作中获取的古籍信息帮助宋辞
  - 第四卷：面临第一次重大考验——万剑盟对宋辞的敌意升级，她被迫在两边之间周旋
  - 第五卷：万剑盟盟主（她的父亲）正式要求她站队。她选择站在宋辞一边——但不是"为了爱情放弃一切"，而是她通过宋辞看到了修真界"另一种可能性"
  - 第六卷：结局——选择留在阴律司（重建后），成为阴律司与万剑盟之间的桥梁。不是"嫁入夫家"而是"找到了自己认同的事业"

### 3. 赵冬铭 — 搭档/凡人视角的锚点

- **身份**：32岁，江城公安局刑警队副队长，宋辞在警局最稳定的工作搭档。纯粹凡人，无任何修真背景，不（会）知道修真世界的存在。但他是一个优秀的刑警——直觉敏锐，观察力强
- **与主角关系**：工作搭档+朋友。他是宋辞在"正常世界"中最稳定的连接点——当他越来越深地卷入修真世界时，赵冬铭的存在提醒着他"你首先是一个法医"
- **性格**：典型的一线刑警性格——粗中有细，办案时认真到偏执，生活中随和到邋遢。对宋辞的"怪异"（遗识触发后的一些反常行为）有察觉但理解为"技术人员的怪癖"
- **外貌**：身高183cm，体格健壮（每周三次健身房，刑警的必修课）。短发，肤色偏黑（常年外勤）。总是穿着不太合身的便衣西装——外套口袋永远鼓鼓囊囊（记录本+香烟+各种零碎）
- **在故事中的作用**：
  - 提供"凡人视角"——读者通过赵冬铭的眼睛看到宋辞的变化，产生"宋辞到底在隐瞒什么"的叙事张力
  - 案件推进的搭档——法医+刑警的标准配置，每一个案件的"双人调查"结构
  - 他在全书中**始终不知道修真世界的存在**——这是一个重要的叙事选择。他的"不知情"是主角必须维护的保护层，也是主角"双重身份"压力的来源
- **发展规划**：
  - 第一卷至第三卷：稳定的工作搭档，案件推进的合作者
  - 第四卷：因为调查一个案件过于接近修真世界的真相，遭遇危险——宋辞在救他和暴露自己之间做出选择。最终赵冬铭被安全救出，但宋辞在他心中的形象开始变化（"宋辞，你到底是什么人？"）
  - 第五卷：赵冬铭选择不再追问——不是放弃，而是信任。他告诉宋辞："我不需要知道所有的答案。但如果你需要我帮忙，我在这里。"这是凡人对修真者最高形式的支持
  - 第六卷：作为"凡人世界"的代表，在结局中见证阴律司的重建——但他看到的只是一个"新成立的跨部门联合调查中心"（阴律司的现代伪装）

### 4. 陈砚北 — 对手/灰色盟友

- **身份**：35岁，丹鼎宗江城分舵副舵主，鼎泰医药研发总监。金丹初期修为。他是丹鼎宗中少有的"改革派"——认为丹鼎宗应该放松对丹药的垄断，否则"迟早会被底层修真者的怨恨反噬"
- **与主角关系**：对手-灰色盟友-潜在的同盟。第一次接触是对立（丹鼎宗的一个黑产案件牵扯到主角的调查），但随着故事推进，主角发现陈砚北和丹鼎宗的主流立场存在差异
- **性格**：优雅的商人+精明的修真者。西装笔挺，言谈滴水不漏。他用商业逻辑思考修真问题——"垄断的最终结局是被打破，与其被别人打破，不如自己主动开放"。但这种"开明"本质上还是精英主义的——他愿意"开放"是因为他认为开放对丹鼎宗更有利，而非出于正义
- **外貌**：标准的企业高管形象——定制西装，金丝边眼镜，保养得当的皮肤和发型。但他的眼睛在不笑的时候会让人感到冷——那不是商人的精明，是金丹期修真者的灵气压力外泄
- **在故事中的作用**：
  - 提供丹鼎宗"内部视角"——他是主角了解丹鼎宗运作方式的窗口
  - 构建"亦敌亦友"的灰色关系——第四卷中，当丹鼎宗保守派决定铲除主角时，陈砚北选择暗中帮助主角——不是因为友谊，而是因为"除掉主角不符合丹鼎宗的长期利益"
  - 代表修真界的"改良派"——他相信规则可以被优化，但不相信规则可以被推翻。这与主角的"破道"形成有趣的对比
- **发展规划**：
  - 第二卷：首次出场，作为案件的对立面
  - 第三卷：与主角多次交锋，两人在智力层面互相尊重
  - 第四卷：当丹鼎宗主战派对主角下杀手时，陈砚北暗中提供帮助——标志性的台词："我帮你不是因为你是对的，而是因为杀了你解决不了问题"
  - 第五卷：在丹鼎宗因天地劫变面临存亡危机时，与主角形成临时联盟
  - 第六卷：丹鼎宗重组后成为新的掌舵人——推行他主张的"开放"政策，但和主角在"开放的幅度"上继续存在分歧。他是主角在修真界重建秩序中的"半盟友半对手"
