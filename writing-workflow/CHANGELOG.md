# Changelog

## 4.0.0 (2026-05-01)

### 架构重构：SKILL 生产与审查分离

**Breaking Change**: quality-review SKILL 拆分为 6 个独立子 SKILL，不再作为单一巨型 SKILL 执行。旧启动模板中对 `quality-review/SKILL.md` 的部分引用（"仅xxx部分"）不再有效。

#### 新增 SKILL（6 个正文审查子 SKILL）
- `continuity-check`: 连续性硬门禁（9项）+ 时间线数值 + 结构质量（25分）
- `character-world-check`: 人物一致性 + 世界观合规（25分）
- `plot-logic-check`: 情节逻辑 + 硬门禁（2项）（15分）
- `commercial-check`: 平台商业化 + 付费设计 + 社交传播（10分）
- `engagement-check`: 硬门禁（4项）+ 文学质量 + 情感体验（18分）
- `ai-compliance-check`: AI 痕迹模式检测（7分）

#### 架构变更
- 生产 SKILL 移除所有自检内容，只做生成
- 审查由独立 subagent 执行，每 agent 配 1 个专用 SKILL
- outline_review/chapter_outline_review: "联合审查组"（1个subagent饰3角）→ 3个独立 subagent
- 所有 SKILL description 统一为中文
- 17 项领域知识从已删除的自检中迁移到审查 SKILL
- 审查结果聚合规则：6 份独立报告 → Coordinator 汇总判定

#### Agent 对齐
- `ai-compliance-officer`: 新增"跨两个阶段工作"说明
- `commercial-editor`: 文学质量职责移至 engagement-reviewer
- `engagement-reviewer`: 新增硬门禁 + 文学质量职责
