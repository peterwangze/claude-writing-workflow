# 商业化审查

独立审查正文的平台算法适配、付费设计和传播潜力。

## 执行 Agent

`writing-workflow/agents/commercial-editor.md`

## 执行程序

### Step 1：加载文件

- `07-content/chapter-XXX.md`（正文）
- `workflow-state.json`（目标平台、字数目标）
- `06-chapter-outlines/chapter-XXX.md`（细纲中的付费转化设计）
- `04-creation-plan.md`（付费策略预设）

### Step 2：平台核心指标检查

根据 `workflow-state.json` 中的目标平台，激活对应的检查清单：

**番茄小说**：
```
□ 前 300 字是否有冲突/异常事件？
□ 每 800 字是否设置了微型悬念？
□ 章节长度是否 ≤ 2500 字？
□ 章节标题是否有吸引力（悬念型/反转型）？
```

**起点中文网**：
```
□ VIP 章开头是否有即时回报（非过渡/回顾）？
□ 章内是否有让读者停留 20 秒+的沉浸点？
□ 是否有"值回票价"的场景？
□ 周二发布的章节质量是否最高？
```

**晋江文学城**：
```
□ 情感描写是否有层次？
□ 角色是否有独特魅力展现？
□ 章末是否有引发读者讨论的话题？
□ 文笔是否达到平台标准？
```

**七猫小说**：
```
□ 节奏是否稳健？
□ 情节是否密集？
□ 语言是否通俗易懂？
□ 字数是否符合平台要求？
```

未达标项数 → 填入 `[___]`

### Step 3：付费设计检查

仅对付费章节激活：

```
□ 付费章开头 300 字内是否有即时回报？
□ 付费章是否有"值回票价"场景？
□ 付费后 3 章爽点密度是否 ≥ 免费部分 1.5 倍？
□ 付费章预期退款风险：[低/中/高]
```

### Step 4：社交传播潜力检查

```
□ 本章是否有读者会主动截屏/分享的段落（Awe+Surprise 节点）？
□ 本章是否存在"我想知道你是怎么想的"讨论触发器？
□ 本章是否有"你必须在场"的社交货币？
```

### Step 5：维度评分（1 个维度，10 分）

| # | 维度 | 满分 | 得分 | 扣分理由 |
|---|------|------|------|---------|
| 8 | 平台商业化 | 10 | | |
| **小计** | | **10** | **[___]/10** | |

**维度 8 细则**：平台核心指标达标、付费卡点设计合理、社交传播潜力、货币化准备度

### Step 6：输出报告

```markdown
# 商业化审查报告 — 第X章

## 平台：[平台名]
- 核心指标达标：[X]/[Y]
- [逐项说明]

## 付费设计（如适用）
- [检查结果]

## 社交传播
- 推荐触发点：[X]处

## 维度评分
- 平台商业化：[X]/10
```
