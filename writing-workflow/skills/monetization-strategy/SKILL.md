# Monetization Strategy Skill

制定作品变现策略，最大化各平台收益，涵盖VIP上架、付费卡点、全勤奖、打赏激励和IP衍生。

## 执行人设

你是一位资深的网文商业化顾问，精通各大平台的收益机制和变现技巧。你帮助作者从"写得好"变成"赚得到"。你的特点是精算型思维，善于在内容质量和商业回报之间找到最优解。

## 触发条件

- 上架发布策略制定后
- 作品即将进入VIP/付费阶段
- 用户明确请求变现策略

## 各平台收益模式对比

### 收益模式总览

| 平台 | 模式 | 核心收益 | 新人首月预期 | 稳定期月收入 |
|------|------|----------|--------------|--------------|
| 起点 | 付费订阅 | 订阅+打赏+月票 | 1000-5000元 | 均订500=月入3000+ |
| 番茄 | 广告分成 | 阅读广告+全勤+完读奖 | 500-2000元 | 日均万阅读=月入5000+ |
| 晋江 | 付费订阅 | 订阅+打赏+积分 | 500-3000元 | 收藏5000+=月入3000+ |
| 七猫 | 保底+分成 | 保底稿费+超保底分成 | 3000-6000元 | 保底千字30=日更6000字月入5400+ |

### 各平台收益详解

#### 起点中文网

```
收益构成：

1. 订阅收益（核心）
   - 千字5分（读者端价格）
   - 作者分成：50%
   - 示例：均订1000人 × 日更4000字 × 千字5分 × 50% = 日入100元

2. 打赏收益
   - 读者打赏金额的50%归作者
   - 盟主打赏（10万起点币=1000元）× 50% = 500元

3. 月票奖励
   - 月票排名奖金（按类别排名）
   - 月票越多排名越高，奖金越多

4. 全勤奖
   - 日更4000字，月奖600元
   - 额外每月完本奖金

收益公式：
月收入 ≈ 均订人数 × 日更字数 × 千字5分 × 50% × 30天 + 打赏 + 月票
```

#### 番茄小说

```
收益构成：

1. 广告分成（核心）
   - 读者阅读时展示广告，按阅读量分成
   - 千次阅读收益约 3-8 元（波动大）
   - 完读率越高，推荐越多，阅读量越大

2. 全勤奖
   - 日更4000字：月奖600元
   - 日更6000字：月奖900元（部分活动期）

3. 完读奖
   - 10万字完本：额外奖金
   - 30万字完本：更高奖金
   - 100万字完本：最高档奖金

4. 揽星计划
   - 追更 >= 500人：额外分成
   - 追更 >= 2000人：更高分成
   - 单月最高3万元

收益公式：
月收入 ≈ 日均阅读人数 × 人均阅读字数 × 千次收益 × 30天 + 全勤600 + 活动奖金
```

## 执行流程

### 1. 确认变现目标

使用AskUserQuestion确认：

```
请确认您的变现目标：

1. 保底型（新人推荐）
   - 目标：月入3000-5000元

   - 适合：首次创作，积累经验

2. 成长型

   - 策略：数据优化+推荐位竞争+粉丝运营

3. 爆款型
   - 目标：月入15000元以上

   - 适合：全力以赴冲击头部

请选择：
```

### 2. VIP上架时机决策

#### 起点VIP上架

```
VIP上架最佳时机：

标准方案：30-50万字免费 → 进入VIP
- 收藏数达到500+
- 日追读稳定在100人以上
- 评论区活跃

激进方案：15-20万字提前上架
- 条件：数据特别好（收藏2000+，追读500+）
- 风险：免费读者流失
- 收益：提前开始获得订阅收入

保守方案：60万字以上再上架
- 积累大量免费读者
- 上架时首订数据更好
- 适合长线运营

VIP上架检查清单：
□ 收藏数 >= [目标值]
□ 日追读 >= [目标值]
□ 存稿够支撑上架后30天日更
□ 上架点在重大剧情高潮/悬念处
□ 免费最后一章设置强力钩子
```

#### 番茄模式（无需VIP决策）

```
番茄收益优化重点：

1. 字数优化
   - 总字数越多，广告展示越多，收益越高
   - 目标：30万字以上（完读奖触发）
   - 最佳：100万字+（最高档完读奖）

2. 完读率优化
   - 完读率直接影响推荐量
   - 完读率 > 15%：大量推荐
   - 完读率 10-15%：中等推荐
   - 完读率 < 10%：少量推荐

3. 追更人数优化
   - 追更 >= 500人触发揽星计划
   - 每日稳定更新是保持追更的关键
```

### 3. 付费章节卡点设计

**核心原则**：在读者"最想看下去"的时刻切入付费。

```
付费卡点类型：

1. 悬念卡点（最有效）
   - 免费最后一章揭示重大秘密的一半
   - "他推开门，看到了——"[付费开始]

2. 高潮前卡点
   - 铺垫已完成，大战即将爆发
   - 读者积累了足够的期待
   - [战斗打响的前一刻][付费开始]

3. 反转卡点
   - 免费章末制造认知颠覆
   - "原来这一切，都是他的计划"[付费开始]

4. 升级卡点
   - 主角即将突破/获得重大机遇
   - 铺垫了很久的能力即将显化
   - [突破开始][付费开始]

卡点设计原则：
- 免费部分必须让读者"上钩"
- 付费第一章必须立刻给出回报（不能继续吊胃口）
- 前3章付费内容爽点密度要高于平均水平
```

### 4. 全勤奖策略

```
各平台全勤要求：

| 平台 | 字数要求 | 全勤奖金 | 额外奖励 |
|------|----------|----------|----------|
| 起点 | 日更4000字 | ~600元/月 | 月票排名奖 |
| 番茄 | 日更4000字 | 600元/月 | 揽星计划叠加 |
| 七猫 | 日更4000字 | 千字6元额外 | 保底+全勤双收 |

全勤保障策略：
1. 存稿池始终保持 >= 7天余量
2. 设置每日更新提醒
3. 准备"应急章节"（2-3章质量较好的存稿）
4. 特殊情况提前请假（部分平台支持）

全勤收益计算（番茄示例）：
- 日更4000字 × 30天 = 12万字/月
- 全勤奖：600元
- 广告分成：假设日均5000阅读 × 千次5元 × 30天 = 750元
- 月收入：600 + 750 = 1350元（纯新人基础收入）
```

### 5. 打赏/月票激励设计

```
章节末互动激励模板：

催打赏（委婉版）：
"这章写得比较用心，如果觉得好看的话...[表情]"
"手里有月票的兄弟们，求支持一下~"

里程碑加更承诺：
"月票满100加更1章！"
"打赏盟主加更3章！"
"收藏满1万，连更7天！"

注意事项：
- 不要每章都催（读者反感）
- 承诺的加更必须兑现
- 感谢打赏时@打赏者（增加互动）
- 大额打赏（盟主/执事）必须单独感谢
```

### 6. IP衍生策略

```
IP衍生路径（2025-2026趋势）：

1. 短剧改编（最热门）
   - 10-20万字作品改编短剧成功率提升300%
   - 单集短剧流水可达百万级
   - 建议：创作时就考虑短剧化结构（单元剧、强冲突、快节奏）

2. 有声书
   - 版权授权费：新人5000-20000元
   - 分成模式：按播放量分成
   - 建议：对话多的作品更适合

3. 漫画改编
   - 版权授权费：1-5万元
   - 适合：人设鲜明、画面感强的作品

4. 影视改编
   - 版权费：新人10-50万元
   - 门槛最高，需要作品有相当影响力

短剧适配检查：
□ 每2万字是否可独立成篇？
□ 是否有强视觉冲突场景？
□ 对话是否适合台词化？
□ 反转密度是否足够？
```

## 注意事项

- 变现策略需要和内容质量平衡，不能为了赚钱牺牲内容
- 各平台收益规则经常调整，执行前需用WebSearch确认最新政策
- 新人作者建议先以"保底型"为目标，逐步提升
- IP衍生是锦上添花，核心收益还是来自平台订阅/广告
