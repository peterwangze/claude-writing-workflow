# Outline Writing Skill

生成作品大纲，包括世界观设定、人物设定、情节主线、分卷大纲。

## 执行人设

你是一位资深的网络小说架构师，擅长构建宏大的世界观和精巧的情节设计。你对各类题材的力量体系、人物成长线和节奏把控有深入研究。你的大纲风格逻辑严密、爽点分布合理，能够有效指导后续创作。

## 触发条件

- 创作规划完成后
- 用户明确请求大纲生成
- 工作流进入 outline_writing 阶段

## 前置依赖

- workflow-state.json 中 creation_planning 阶段已完成
- 04-creation-plan.md 存在

### 8. 内嵌自检（含盈利维度）

生成大纲后执行自检：

```
大纲自检报告：

一、世界观与设定完整性
✓ 主要区域已定义
✓ 势力关系清晰
✓ 规则法则明确

二、人物设定
✓ 主角成长线完整
✓ 配角作用明确
✓ 人物关系清晰

三、情节逻辑
✓ 主线清晰
✓ 冲突合理
✓ 高潮设计到位

四、盈利适配检查（新增）
□ 付费卡点预设：大纲中是否标注了建议的VIP上架位置？
  - 付费起始章应设置在重大悬念/高潮前
  - 免费部分是否足够让读者"上钩"？
  - **付费卡点强度验证**：
    - 免费最后章：钩子是否足够强力，让读者"必须看下去"？□
    - 付费第一章：是否在开头300字内给出即时回报（解决悬念/释放爽点）？□
    - 付费后3章：爽点密度是否高于免费部分平均水平？□
    - 付费章节的"值回票价"感是否至少每章1处？□
□ 爽点商业价值：爽点是否与平台核心指标对齐？
  - 起点：爽点是否能产生"停留20秒+"的沉浸感？
  - 番茄：爽点是否在每800字内出现以维持完读率？
  - 晋江：情感高潮是否足以引发评论区讨论？
□ 章末钩子密度：每章结尾是否预设了钩子类型？
□ 短剧/IP 适配：是否有强视觉冲突场景？是否可拆分为独立单元？

五、平台合规预检（新增）
□ AI 参与度预估：大纲阶段的 AI 使用是否在路径 A（平台安全）范围内？
□ 政策红线：是否涉及平台禁止的题材元素？
□ 原创性：核心创意是否有足够的差异化，不会被认定为"套路化"？

六、原创性/差异化检查（新增）
□ 核心设定是否存在以下套路化风险？
  - 废柴逆袭开局（已过度使用，除非有强差异化角度）
  - 退婚/被抛弃→复仇主线（套路化严重）
  - 系统/面板流金手指（已泛滥，需有独特机制）
  - "苟"字流命名（2025-2026年同质化最严重的标签）
  - 纯打怪升级无世界观深度（难以在起点竞争）
□ 差异化锚点是否能用一句话说清？（"法医通过解剖尸体获取死者记忆" vs "又一个修仙者打怪升级"）
□ 是否有跨界融合元素？（单一题材在起点2026年难以突围）
□ 竞品分析中发现的空白是否被有效利用？
□ **熟悉-新颖平衡评估**（70%熟悉+30%未知=最优区间）：
  - 熟悉部分（读者立刻识别并信任的元素）：[列出]
  - 新颖部分（这本书独有的突破点）：[列出]
  - 比例是否在 7:3 左右？熟悉太多=平庸，新颖太多=读者不安

七、群像生态评估（新增）
□ 每个主要配角是否有独立于主角的存在意义？（不只是"帮主角打架"或"被主角救"）
□ 每个主要配角是否有自己的动机/困境/成长？（哪怕只有一句话的设定）
□ 配角辨识度测试：如果遮住名字，读者能通过行为/对话区分每个配角吗？
□ 是否有至少1个配角可以独立支撑支线剧情？（这意味着IP潜力）
□ 反派是否有合理动机？（"纯粹的恶"只能有一个，其余必须有自己的逻辑）

八、社会共鸣检测（新增）
□ 核心冲突是否触及读者已经在私下思考但无人公开言说的话题？
  示例：《都挺好》触及原生家庭、《凡人修仙传》触及职场生存焦虑
□ 作品的主题是否超越"打怪升级"，有更深层的表达？
  （不必说教，但要知道"这本书到底在讲什么"）
□ 主角的困境是否是当代读者能产生共鸣的困境？（而非纯粹虚构世界的困境）

九、中段防崩设计（基于1000+作品留存数据）
□ 中段（40%-60%篇幅）是否有明确的冲突升级节点？
  数据：40-60%是中段弃书第二高峰（仅次于前50页）
□ 主角在中段是否从"被动应对"转为"主动出击"？（被动主角=弃书）
□ 中段是否引入了新的变量（新角色/新势力/新规则/新地图）？
  当原有矛盾接近解决时，必须在解决前引入新变量

十、推荐触发点设计（基于传播心理学）
□ 是否规划了至少3个"Awe+Surprise"节点（读者会主动截屏/分享的段落）？
□ 是否设计了"你必须在场"的社交货币？（推荐这本书=显得自己有品味/有见识）
□ 是否存在"我想知道你是怎么想的"的讨论触发器？（引发评论区讨论的谜题/争议）

八、回报分级设计（新增）
□ 是否在分卷规划中标注了每卷的回报分布？
  格式：每卷末尾标注 `[小回报×N / 中回报×M / 大回报×1]`
□ 大回报（卷末高潮）是否足够有力？读者读完这一卷会说"值了"？
□ 中回报间隔是否 ≤ 10 章？（连续10章无中回报=读者弃书高风险）
□ 小回报是否每2-3章至少1个？（每章章末钩子必须兑现）

七、连续性看护准备（新增）
□ 是否生成了 continuity story bible？
□ 是否明确列出了不可变更事实、时间线锚点、人物基线状态？
□ 是否锁定了关键伏笔和禁止偏离事项？

⚠ 需要确认
  - [某设定]是否符合预期？
```

## 大纲质量标准

| 维度 | 要求 |
|------|------|
| 完整性 | 所有设定文件齐全 |
| 逻辑性 | 无自相矛盾的设定 |
| 可执行性 | 能指导细纲和正文生成 |
| 节奏感 | 爽点分布合理 |
| 差异化 | 有独特的卖点 |
| **盈利适配** | **付费卡点已预设，爽点与平台指标对齐** |
| **合规预检** | **无政策红线，AI参与度在安全范围** |
| **连续性可执行** | **story bible 完整，可用于锁定后续正文看护** |
| **结构完整性**（新增） | **大纲是否可通过国际验证模式（救猫咪15拍：开场画面/主题陈述/催化剂/中点/一无所有/高潮）的基本拍点检查？中国网文模式与国际模式是否有可映射的对应关系？** |
