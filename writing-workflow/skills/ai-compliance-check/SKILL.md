# AI 合规审查

独立审查正文的 AI 痕迹密度和原创性辨识度。免责声明：此评估由 AI 完成，有结构性盲点，不能替代平台审核。

## 执行 Agent

`writing-workflow/agents/ai-compliance-officer.md`

## 执行程序

### Step 1：加载文件

- `07-content/chapter-XXX.md`（正文）
- `13-creation-logs/`（历史创作日志，如有）

### Step 2：AI 痕迹逐段检测

| 段落位置 | 痕迹类型 | 原文摘录 | 问题描述 | 修改建议 |
|----------|---------|---------|---------|---------|
| 第X段 | [类型] | "[原文前20字...]" | [问题] | [建议] |

**检测规则**：

| 痕迹类型 | 检测规则 | 示例 |
|----------|----------|------|
| 句式规整 | 连续 3 句以上相同句式结构 | "他做了A。他做了B。他做了C。" |
| 过渡词重复 | 同一段落出现 3 次以上相同过渡词 | "然后...然后...然后..." |
| 形容词堆砌 | 连续使用"非常"、"十分"等程度副词 | "非常美丽，十分动人" |
| 情感直白 | 直接描述情感而非通过行为表现 | "他感到很伤心" |
| 缺乏细节 | 抽象描述多于具体描写 | "风景很美" vs "远山如黛，近水含烟" |
| 价值观说教 | 过于直白的价值观表达 | "这告诉我们一个道理..." |

**统计**：
- 检测段落总数：[X]
- 发现痕迹段落：[Y]
- 痕迹密度：[Y/X × 100]%
- 痕迹密度判定：[≤15%合格 / 15-30%需优化 / >30%不合格]

### Step 3：AI 参与度分级

```
AI 参与级别：[A 平台安全 / B 灰区 / C 高风险]
AI 辅助范围：[校对/灵感/粗纲 / 部分初稿改写 / 完整章节生成]
人类主导部分：[核心创意/情节/情感/全文]
```

**路径 C 阻断规则**：若评为路径 C，必须明确告知该内容不适合平台签约投稿。

### Step 4：证据链完整性检查

```
□ 人工原稿/构思记录：[有/无]
□ AI 对话过程留存：[有/无]
□ AI 输出首稿留存：[有/无]
□ 改写前后对照：[有/无]
□ 投稿前确认声明：[有/无]
```

### Step 5：写作质量检测（内控项）

以下检查用于发现机械化表达，**不等同于平台官方审核标准**：

**句式多样性**：统计连续 3 句以上相同句式 → [通过/待优化]

**过渡词密度**：每 500 字 < 3 个相同过渡词
- 高风险词："然后"（每段≤1次）、"于是"（每章≤5次）、"接着"（每章≤3次）、"所以"（每章≤3次）
→ [通过/待优化]

**情感表达自然度**：每章直接情感表达（"感到+情感词"结构）< 3 处 → [通过/待优化]

**对话口语化程度**：口语化对话 > 80% → [通过/待优化]

**场景感官描写丰富度**：感官描写 > 60%（非抽象概括） → [通过/待优化]

### Step 6：维度评分（1 个维度，7 分）

|---|------|------|------|---------|
| 9 | AI痕迹+原创 | 7 | | |

**维度 9 细则**：AI 痕迹密度 ≤15% 合格、有个人风格辨识度（非模板化表达）
