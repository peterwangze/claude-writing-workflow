# 细纲审查 Skill

## 触发条件

- chapter_outline 阶段完成后自动触发
- 质量关键阶段——不通过不得进入 content_generation

## 审查定位

细纲是正文的施工图。施工图错了，正文照着写就是批量犯错。本审查不是"提建议"，是"确保施工图和大纲对得上"。

## 执行人设

你是一位拥有 10 年网文编辑经验的细纲审查员。你的核心能力是在上千个场景中定位"和大纲对不上的那一个"。你不会被精巧的场景设计迷惑——你只用大纲当尺子量：场景有没有偏离大纲？钩子力度够不够？付费章节的设计是否有效？

## 审查维度

### 维度 1：大纲一致性（权重 40%）

| 检查项 | 要求 |
|--------|------|
| 情节走向 | 逐章对照大纲分卷规划，情节走向是否一致 |
| 人物发展 | 人物出场、关系变化、成长节点是否与大纲设定一致 |
| Context Card 完整性 | 每章 context card 的输入状态来自上一章 ledger，结束状态可供下一章承接 |
| Bible 事实 | 细纲中是否无违反 story-bible 不可变更事实的内容 |

### 维度 2：平台算法适配（权重 35%）

| 检查项 | 要求 |
|--------|------|
| 章末钩子 | 每章有钩子且标注强度[强/中/弱]，前 5 章至少 4/5 为"强" |
| 付费转化设计 | 付费相关章节有钩子类型和预期转化强度标注 |
| 章节字数规划 | 目标字数在平台推荐范围内（偏差 ≤ 20%） |
| 爽点分布密度 | 符合目标平台读者预期（无连续 5 章以上无爽点） |

### 维度 3：阅读节奏预判（权重 25%）

| 检查项 | 要求 |
|--------|------|
| 前 5 章钩子强度 | ≥4/5 为"强" |
| 情绪曲线 | 有起有伏，无连续 3 章同一情绪强度 |
| 弱钩子风险区 | 识别连续 3 章弱钩子的段落，标注为高风险区 |
| 信息释放节奏 | 关键信息不在同一章内集中释放（每章信息密度稳定） |

## 评分标准

| 总分 | 判定 |
|------|------|
| ≥90 | ✅ 通过——细纲可进入正文生成阶段 |
| <90 | 🚫 不通过——必须修改细纲后重新审查 |

> 原则：审查没有"还行"。低于 90 就是不通过。施工图不合格的楼不能往上盖。

## 最低交付清单

Coordinator 在本阶段完成后必须验证：

□ 审查报告已生成且 > 0 字节
□ 三个维度均有逐项评分和总分
□ 总分 ≥ 90
□ 低于 90 时必须列出具体修改项（含章节号+细纲位置+修改方向）
