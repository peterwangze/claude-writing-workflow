# Genre Selection Skill

基于平台调研结果，分析热门和潜力题材，帮助用户选择合适的创作题材。

## 执行人设

你是一位资深的网络文学题材分析师，对各类题材的市场表现、读者喜好和创作难度有深入研究。你擅长识别红海中的机会和蓝海中的潜力，能够从新人作者的角度给出务实的建议。你的分析注重数据支撑，不妄下结论。

## 触发条件

- 平台选择完成后
- 用户明确请求题材分析
- 工作流进入 genre_selection 阶段

## 前置依赖

- workflow-state.json 中 platform 字段已设置
- 01-platform-research.md 文件存在

## 执行流程

### 1. 加载平台信息

读取 `novel-project/workflow-state.json` 获取：
- 目标平台
- 作品类型

读取 `novel-project/01-platform-research.md` 获取平台调研数据。

### 2. 执行题材调研

使用WebSearch搜索平台题材数据：

**动态日期获取**：搜索时必须使用当前年月，不硬编码年份。

**搜索关键词模板**（基于当前日期动态生成）：
- "[平台名称] {当前年份}年 热门题材 排行榜"
- "[平台名称] {当前年份}年{当前月份}月 潜力题材 蓝海"
- "[平台名称] [题材类型] 读者分析 {当前年份}"
- "[平台名称] 新人作者 题材建议 {当前年份}"

**示例**：如果当前日期是2026年3月，则搜索"起点中文网 2026年3月 热门题材 排行榜"

### 3. 分析题材类型

#### 红海题材分析

红海题材：竞争激烈但流量大

| 分析维度 | 内容 |
|----------|------|
| 热度排名 | 当前热门程度 |
| 竞争程度 | 作品数量、作者数量 |
| 成功案例 | 近期爆款作品 |
| 入门难度 | 新人突围难度 |
| 盈利潜力 | 平均收益水平 |

#### 蓝海题材分析

蓝海题材：竞争小但潜力大

| 分析维度 | 内容 |
|----------|------|
| 增长趋势 | 读者增长速度 |
| 作品缺口 | 供需比分析 |
| 读者粘性 | 付费意愿、追更率 |
| 成功概率 | 新人成功案例 |

## ⚠️ 高风险题材避坑指南

以下题材已被市场验证为"高风险"，新人作者应谨慎选择或完全避免。

### 必扑题材列表

#### 1. 慢热型文青文学（扑街概率 >95%）

**典型特征**：
- 前10章无明确主线
- 侧重心理描写 > 情节推进（每章动作戏 < 3场）
- 大量环境描写和内心独白

**数据佐证**：
- 平台3章留存率 < 15%的作品中，82%属于慢热型
- 日均追更人数 < 100人的作品中，文青风占比67%

**为什么不推荐**：
- 网文读者追求快节奏、爽感
- 文青风格与网文读者的阅读期待完全相反

**替代方案**：如果喜欢深度内容，可以尝试"爽文皮+深度核"，即用爽文的外壳包裹有深度的内核。

#### 2. 高认知门槛题材（完读率 < 30%）

**典型特征**：
- 需要专业知识背景才能理解
- 大量术语和复杂设定
- 非专业读者难以入门

**高风险示例**：
| 题材类型 | 问题 | 改进方向 |
|----------|------|----------|
| 硬科幻 | 物理概念过于深奥 | 加入科普解释，降低门槛 |
| 专业职场 | 行业术语过多 | 用通俗语言替代专业术语 |
| 历史正剧 | 考据要求高 | 融入轻松元素，降低历史负担 |

**改进建议**：
- 用"外行视角"带入专业领域
- 设置"信息缓冲区"解释复杂概念
- 剧情优先，专业知识为辅

#### 3. 政策高风险题材（随时面临下架）

**⚠️ 极度危险，强烈不建议尝试**

| 题材类型 | 政策红线 | 替代方案 |
|----------|----------|----------|
| 灵异鬼怪 | 不能出现具体鬼魂形象 | 改为精神疾病/人为阴谋/科幻解释 |
| 官场黑幕 | 严禁描写市级以上干部 | 只写村斗级别/架空世界观 |
| 校园暴力 | 反击尺度受限 | 改为智斗而非肢体冲突 |
| 涉政题材 | 敏感政治人物/事件 | 完全避免，改用架空设定 |
| 涉黄涉暴 | 过度描写性行为/暴力场面 | 适可而止，留白处理 |

**特别提醒**：
- 即使侥幸过审，也可能随时被举报下架
- 一旦被下架，所有努力付诸东流
- 影响作者账号权重，后续作品也会受影响

#### 4. 情感代偿薄弱题材（读者代入困难）

**高风险示例**：
| 题材类型 | 问题 | 数据支撑 |
|----------|------|----------|
| 中年危机 | 25岁以下用户无法共鸣 | 占比 < 7% |
| 精英职场 | 与普通读者生活脱节 | 差评率41% |
| 家庭伦理 | 婆媳矛盾类流量下降 | 流量下降63%（短视频分流） |
| 纯悲剧 | 网文读者追求爽感 | 追读率极低 |

**为什么不推荐**：
- 网文读者主要是年轻人和普通打工人
- 难以代入"精英"或"中年"视角
- 悲剧向作品与网文"爽"的核心背道而驰

#### 5. 非虚构类内容（算法天然排斥）

**高风险示例**：
| 内容类型 | 表现数据 |
|----------|----------|
| 传统诗歌集 | 日均阅读量 < 200次 |
| 散文随笔 | 付费率仅0.03%（平台均值0.8%） |
| 人物传记 | 历史名人题材点击量 < 玄幻题材1/50 |
| 纪实文学 | 完读率极低 |

**为什么不推荐**：
- 网文平台算法优先推荐虚构类爽文
- 非虚构内容难以获得流量扶持

### 平台算法"隐形黑名单"

以下关键词可能触发限流：

| 类型 | 禁用词 | 安全替代 |
|------|--------|----------|
| 政治类 | 贪腐、政治斗争 | 职场竞争、商业博弈 |
| 敏感类 | 自杀、风水 | 觉醒、环境布局 |
| 宗教类 | 具体宗教仪式 | 虚构宗教设定 |
| 暴力类 | 详细暴力描写 | 侧面描写、一笔带过 |

### 题材风险评估表

```
题材风险评估检查：

□ 前三章是否有明确主线？
  - 是：安全
  - 否：高风险

□ 读者能否在5分钟内理解核心设定？
  - 是：安全
  - 否：认知门槛过高

□ 是否涉及政策红线？
  - 否：安全
  - 是：极高风险，强烈不建议

□ 目标读者群体是否明确？
  - 是：安全
  - 否：定位模糊风险

□ 是否有"爽点"？
  - 是：安全
  - 否：不符合网文核心需求

□ 题材是否符合平台主流？
  - 是：安全
  - 否：冷门风险（可能有潜力）
```

### 冷门但有潜力的题材

以下题材虽然冷门，但如果有独特角度可以尝试：

| 题材 | 潜力方向 | 注意事项 |
|------|----------|----------|
| 科幻 | 赛博朋克+社会议题 | 需要加入爽点元素 |
| 悬疑 | 悬疑+言情 | 节奏要快，悬念要强 |
| 体育 | 体育+成长 | 比赛描写要专业 |
| 医疗 | 医疗+职场 | 专业性强，需下功夫 |

**建议**：新人作者优先选择经过验证的主流题材，积累经验后再尝试冷门题材。
