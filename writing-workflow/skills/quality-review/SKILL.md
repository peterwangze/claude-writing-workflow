# Quality Review Skill

多维度质量审查，包括一致性检查、文风检查、AI痕迹消除。

## 执行人设

你是一位严谨的小说质量审查专家，拥有多个视角的审查能力。你能够从架构、节奏、人物、文风、AI痕迹等多个维度评估内容质量。你的审查风格客观公正、问题精准，给出的修改建议具体可行。

## 触发条件

- 大纲生成后（自动）
- 细纲生成后（自动）
- 每章正文生成后（自动）
- 用户明确请求质量审查

## 审查阶段

| 阶段 | 审查重点 | 审查角色 |
|------|----------|----------|
| 大纲 | 世界观完整性、设定逻辑性、节奏合理性 | 架构审查员、节奏审查员、用户画像审查员 |
| 细纲 | 与大纲一致性、章节连贯性 | 情节审查员、连贯性审查员 |
| 正文 | 人物一致性、前后文连贯性、文风、AI痕迹 | 连贯性审查员、人物审查员、文风审查员、AI痕迹审查员 |

## 执行流程

### 1. 确定审查类型

根据触发条件确定审查类型：
- outline_review：大纲审查
- chapter_outline_review：细纲审查
- content_review：正文审查

### 2. 加载审查内容

根据审查类型加载对应文件：
- 大纲审查：05-outline.md, 08-characters/, 09-worldbuilding/
- 细纲审查：06-chapter-outlines/chapter-XXX.md, 05-outline.md
- 正文审查：07-content/chapter-XXX.md, 06-chapter-outlines/, 08-characters/

## AI痕迹检查详解

### 检测规则

| 痕迹类型 | 检测规则 | 示例 |
|----------|----------|------|
| 句式规整 | 连续3句以上相同句式 | "他做了A。他做了B。他做了C。" |
| 过渡词重复 | 同一段落出现3次以上相同过渡词 | "然后...然后...然后..." |
| 形容词堆砌 | 连续使用"非常"、"十分"等程度副词 | "非常美丽，十分动人" |
| 情感直白 | 直接描述情感而非通过行为表现 | "他感到很伤心" |
| 缺乏细节 | 抽象描述多于具体描写 | "风景很美" vs "远山如黛，近水含烟" |
| 价值观说教 | 过于直白的价值观表达 | "这告诉我们一个道理..." |

### 优化示例

**原文（AI痕迹明显）**：
> 他感到非常愤怒，因为这件事情让他觉得很不公平。他的内心充满了复杂的情绪。

**优化后**：
> 他攥紧了拳头，指节泛白。桌上那杯茶已经凉透了，就像他此刻的心。三年了，他等了三年，换来的却是这样的结果。

## 质量标准

### 大纲质量标准
- 世界观完整，无矛盾
- 人物设定清晰
- 情节逻辑合理
- 节奏规划明确

### 细纲质量标准
- 与大纲一致
- 场景描述具体
- 人物行为合理
- 爽点设计到位

### 正文质量标准
- 与设定一致
- 前后文连贯
- 文风符合平台
- AI痕迹轻微或无

## 审查角色详解

### 架构审查员
负责检查世界观和设定的完整性和逻辑性：
- 世界观是否自洽
- 设定是否有矛盾
- 力量体系是否合理

### 节奏审查员
负责检查情节节奏和爽点分布：
- 爽点频率是否合适
- 高潮设计是否到位
- 铺垫与推进比例是否合理

### 用户画像审查员
负责检查内容是否符合目标用户：
- 题材是否符合平台用户偏好
- 节奏是否符合目标读者习惯
- 文风是否符合平台风格

### 情节审查员
负责检查情节的一致性和完整性：
- 情节走向是否符合大纲
- 细节是否完整
- 逻辑是否合理

### 连贯性审查员
负责检查内容的连贯性：
- 时间线是否连续
- 场景转换是否自然
- 情绪过渡是否流畅

### 人物审查员
负责检查人物的一致性：
- 行为是否符合人设
- 对话风格是否一致
- 情绪变化是否合理

### 文风审查员
负责检查文风是否符合要求：
- 是否符合平台风格
- 节奏控制是否得当
- 语言是否流畅

### AI痕迹审查员
负责检查和消除AI生成痕迹：
- 句式是否过于规整
- 过渡词是否重复
- 情感表达是否直白
- 是否缺乏细节描写

## 平台AI检测规避检查

### ⚠️ 当前平台政策（2025-2026）

| 平台 | AI政策 | 检测手段 | 违规后果 |
|------|--------|----------|----------|
| 起点中文网 | 全面禁止，要求100%人工创作 | 算法检测+人工审核 | 作品下架 |
| 番茄小说 | 全面禁止，AI占比>**15%-20%**审核不通过 | 连续性检测+文风分析 | 全勤取消、限流、封号 |
| 晋江文学城 | 分级限制，禁止纯AI生成 | AI痕迹识别+举报机制 | 锁章、黄牌、禁榜 |
| 七猫小说 | AI内容>**15%-20%**审核不通过 | 算法检测 | 作品下架 |

**⚠️ 重要更新（2025-2026）**：各大平台AI容忍度已从30%收紧至**15%-20%**，建议将AI痕迹控制在**10%以下**确保安全。

### AI检测必过检查项

生成内容必须通过以下检测才能通过平台审核：

#### 1. 句式多样性检测

```
检测方法：统计连续3句以上相同句式结构
通过标准：无连续3句以上相同结构

示例（不通过）：
他走到门前。他推开门。他走了进去。他看到了一张桌子。

修正（通过）：
三步并作两步，他推开了那扇吱呀作响的木门。屋里光线昏暗，一张老式八仙桌横在正中。
```

#### 2. 过渡词密度检测

```
检测方法：统计"然后、于是、接着、然而、因此"等过渡词频率
通过标准：每500字<3个相同过渡词

高风险词表：
- "然后"（每段不超过1次）
- "于是"（每章不超过5次）
- "接着"（每章不超过3次）
- "所以"（每章不超过3次）
```

#### 3. 情感表达检测

```
检测方法：识别"感到+情感词"、"觉得+情感词"结构
通过标准：每章直接情感表达<3处

不通过示例：
- 他感到非常愤怒
- 她觉得十分开心
- 他的内心充满了复杂的情绪

修正方法：改为行为或细节描写
- 他攥紧了拳头，指节泛白
- 她眼角弯成了月牙
- 三年了，他等了三年，换来的却是这样的结果
```

#### 4. 形容词密度检测

```
检测方法：统计"非常、十分、特别、极其"等程度副词
通过标准：连续使用<2个，每章<10个

高风险词：
非常、十分、特别、极其、相当、格外、异常
```

#### 5. 对话自然度检测

```
检测方法：检测对话是否过于书面化
通过标准：口语化对话占比>80%

不通过示例：
"我认为我们应该采取行动来解决这个问题。"

修正：
"得动手了，再拖下去黄花菜都凉了。"
```

#### 6. 场景感官度检测

```
检测方法：检测抽象描写vs感官描写比例
通过标准：感官描写占比>60%

抽象描写（风险）：
- 这是一个很美丽的风景
- 她长得非常漂亮

感官描写（安全）：
- 远山如黛，近水含烟，风里带着股淡淡的桂花香
- 她眉眼间带着股英气，眼尾微微上挑
```

### AI痕迹自动优化

检测到AI痕迹后，自动生成优化建议：

| 原文类型 | AI痕迹 | 优化方向 | 示例 |
|----------|--------|----------|------|
| 情感直白 | "他感到非常愤怒" | 行为描写 | "他攥紧拳头，指节泛白" |
| 形容词堆砌 | "非常美丽，十分动人" | 具体描写 | "眉眼如画，一笑生花" |
| 过渡词重复 | "然后...然后...然后..." | 变换表达 | 删除或用动作连接 |
| 句式规整 | "他做了A。他做了B。" | 合并变化 | "三步并作两步，他..." |
| 书面对话 | "我认为应该..." | 口语化 | "得..."、"要不..." |
| 抽象描写 | "风景很美" | 感官描写 | 添加视觉、听觉、嗅觉细节 |
