# 大纲审查

## 执行程序

按以下 12 步机械执行。每一步都必须产出书面结果。跳过任一步 = 审查无效。

### 第一步：加载文件

打开以下文件，确认全部可读取：
- `05-outline.md`
- `08-characters/main-characters.md`
- `08-characters/supporting-characters.md`
- `08-characters/character-relationships.md`
- `09-worldbuilding/world-settings.md`
- `09-worldbuilding/power-system.md`
- `17-continuity/story-bible.md`

### 第二步：数不可变更事实

1. 打开 `story-bible.md`，找到 `## 不可变更事实` 章节
2. 数条目数量 → 填入 `[___] 条`（要求 ≥5）
3. 逐条检查：每条是否有"违反后果"说明？→ 填入 是/否
4. 任一条无后果说明 → 扣 5 分

### 第三步：数伏笔

1. 打开 `05-outline.md`，找到 `## 伏笔设计` 表
2. 打开 `story-bible.md`，找到 `## 关键伏笔清单`
3. 数数量和字段完整性 → 填入 `[___] 个伏笔`（要求 ≥5）
4. 逐伏笔检查：是否有编号？是否有埋设章节？是否有最迟回收章节？是否有当前状态？→ 填入 是/否
5. 任一个伏笔缺字段 → 扣 3 分

### 第四步：检查时间线锚点

1. 打开 `story-bible.md`，找到 `## 时间线锚点`
2. 数节点数量 → 填入 `[___] 个`（要求 ≥3）
3. 逐节点检查：前后节点间是否有因果链？→ 填入 是/否
4. 任意两个节点间无因果链 → 扣 5 分

### 第五步：检查禁止偏离事项

1. 打开 `story-bible.md`，找到 `## 禁止偏离事项`
2. 数条目 → 填入 `[___] 条`（要求 ≥5）
3. 逐条检查：是否具体？（反例："不得无铺垫新增设定" ← 这是万金油，不合规）
4. 任一条为万金油表述 → 扣 3 分

### 第六步：检查主角成长弧线

1. 打开 `main-characters.md`，找到主角的 `### 成长线` 表格
2. 逐阶段检查：是否有起点状态？是否有转折事件？是否有目标状态？是否有触发事件？是否有代价？
3. 缺任一字段 → 扣 5 分

### 第七步：检查配角独立性

1. 打开 `main-characters.md`，找到每个主要配角
2. 逐个问：这个配角的动机是否独立于主角？（反例：动机是"帮助主角"=不合规）
3. 不合规配角数 → 填入 `[___] 个`
4. 每个不合规配角 → 扣 3 分

### 第八步：检查力量体系

1. 打开 `power-system.md`
2. 检查：每个等级是否有晋升条件？是否有资源消耗？是否有失败风险？是否有副作用？
3. 缺任一字段 → 扣 5 分
4. 检查：是否有"实力差距"量化说明？→ 无 → 扣 3 分

### 第九步：检查世界观自相矛盾

1. 打开 `world-settings.md`
2. 通读全文，标记任何自相矛盾的陈述
   （例：前文说"灵气极其稀有"，后文说"每个修士都有大量灵石"）
3. 矛盾数 → 填入 `[___] 处`
4. 每处矛盾 → 扣 10 分

### 第十步：检查盈利适配

1. 打开 `05-outline.md`，找到 `## 分卷大纲`
2. 每卷是否标注了建议的 VIP 上架位置？→ 填入 是/否
3. 未标注 → 扣 10 分
4. 付费起始章是否有理由说明？→ 无 → 扣 5 分

### 第十一步：检查差异化卖点

1. 打开 `05-outline.md` 或 `03-novel-info.md`
2. 用一句话写出"这本书和同类作品最大的不同" → `[一句话]`
3. 如果写不出一个具体的差异化锚点 → 扣 10 分

### 第十二步：逐项计分

## 判定

| 总分 | 判定 |
|------|------|
| ≥90 | ✅ 通过 |
| <90 | 🚫 不通过——必须修改后重审 |
