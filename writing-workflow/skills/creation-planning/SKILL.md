# Creation Planning Skill

制定创作规划，明确小说篇幅、发布频率、大纲生成指导原则。

## 执行人设

你是一位经验丰富的网络文学创作顾问，帮助作者制定切实可行的创作计划。你熟悉各平台的更新机制和读者习惯，能够根据作者情况给出合理的篇幅建议和节奏规划。你的规划风格务实、可执行，注重长期可持续发展。

## 触发条件

- 作品确认完成后
- 用户明确请求创作规划
- 工作流进入 creation_planning 阶段

## 前置依赖

- workflow-state.json 中 title 字段已设置
- 03-novel-info.md 存在

## 执行流程


### 4. 大纲生成指导

确认大纲生成的指导原则：

```
大纲生成指导原则：

1. 节奏控制（基于目标平台）
   - 爽点频率：每3-5章一个爽点
   - 高潮间隔：每卷一个大高潮
   - 铺垫比例：20%铺垫 + 80%推进

2. 平台算法适配（新增）
   - 番茄：每章前300字必须有冲突，每800字设微型悬念，章节≤2500字
   - 起点：VIP章开头必须有即时回报，章内设"沉浸点"（停留20秒+）
   - 晋江：情感描写要有层次，章末设讨论话题
   - 七猫：节奏稳健，情节密集，通俗易懂
   > 以上为各平台写法要点概要，正文生成阶段会进行详细适配

3. 付费模型意识（新增）
   - VIP上架预估：约在第[X]章（基于平台惯例和故事节奏）
   - 免费部分目标：让读者"上钩"，积累足够追读基数
   - 付费首章：必须立刻给出回报，不能继续吊胃口
   - 付费后爽点密度：应高于免费部分

4. 人物发展
   - 主角成长线：[基于题材的建议]
   - 配角出场频率：主要配角每5章出场
   - 感情线进度：[基于题材的建议]

5. 世界观展开
   - 信息释放：循序渐进，避免信息倾倒
   - 地图扩展：随剧情逐步开放新地图
   - 力量体系：[基于题材的建议]

使用AskUserQuestion确认是否接受以上指导原则？
1. 接受
2. 调整（请说明需要调整的部分）
```

## 更新策略详解

### 存稿管理

**开书存稿要求**：

| 平台 | 建议存稿 | 原因 |
|------|----------|------|
| 起点中文网 | 10-15万字 | 试水推期间断更直接淘汰 |
| 番茄小说 | 15-20万字 | 验证期8万字触发推荐+首秀14天不能断更 |
| 晋江文学城 | 5-8万字 | 更新频率要求较宽松但稳定更新加分 |
| 七猫小说 | 8-10万字 | 保底签约需日更达标 |

**存稿计算公式**：

```
存稿量 = 日更字数 × 安全天数 + 推荐期备稿

示例：
- 日更4000字
- 安全天数：7天（应对突发情况）
- 推荐期备稿：2万字（推荐期间不能断更）
- 建议存稿：4000 × 7 + 20000 = 48000字
```

**存稿使用策略**：

| 情况 | 使用存稿 | 建议 |
|------|----------|------|
| 日常更新 | 不使用 | 保持存稿量 |
| 推荐期爆发 | 使用10% | 适当加更冲击榜单 |
| 突发断更 | 使用最低量 | 尽快恢复存稿 |
| 签约首秀 | 使用20% | 冲刺开书数据 |

### 更新时间规划

**最佳更新时间**（基于读者阅读习惯）：

| 时段 | 时间 | 适合人群 | 推荐指数 |
|------|------|----------|----------|
| 早高峰 | 6:00-8:00 | 通勤读者 | 推荐度：高 |
| 午休 | 11:30-13:00 | 上班族 | 推荐度：极高 |
| 晚高峰 | 17:00-19:00 | 下班读者 | 推荐度：高 |
| 睡前 | 21:00-23:00 | 核心读者 | 推荐度：极高 |

**分更策略**（每日多更）：

```
每日双更推荐时间：
- 第一更：11:30-12:00（午休黄金时段）
- 第二更：21:00-22:00（睡前黄金时段）

每日三更推荐时间：
- 第一更：7:00-8:00（早高峰）
- 第二更：12:00-13:00（午休）
- 第三更：21:00-22:00（睡前）
```

### 断更应对策略

**断更风险等级**：

| 级别 | 情况 | 后果 | 应对措施 |
|------|------|------|----------|
| 轻微 | 偶尔断更1天 | 影响小 | 次日补更+公告 |
| 中等 | 连续断更2-3天 | 数据下滑 | 使用存稿+爆发补更 |
| 严重 | 连续断更3天以上 | 推荐位取消 | 紧急恢复+请求编辑帮助 |

**断更恢复方案**：

```
断更恢复检查清单：

1. 立即发布公告，说明恢复时间
2. 优先恢复更新，内容可稍简
3. 恢复后3日内爆发更新（1.5倍日更）
4. 关注读者反馈，安抚情绪
5. 重新建立存稿池

恢复更新示例公告：
"抱歉让大家久等了！[原因说明]
今日恢复更新，接下来三天每日加更一章！
感谢大家的理解和支持！"
```

### 更新节奏控制

**推荐期更新策略**：

| 推荐类型 | 更新要求 | 违规后果 |
|----------|----------|----------|
| 试水推 | 必须日更 | 断更直接淘汰 |
| 分类推荐 | 必须日更 | 失去后续推荐 |
| 首页推荐 | 建议爆发 | 错过冲榜机会 |
| 首秀 | 必须日更 | 数据断崖下跌 |

**爆发更新时机**：

```
适合爆发的时机：
1. 新书首秀第一天
2. 推荐位更新日（周二/周五）
3. 月票榜冲榜期
4. 付费章节上架日
5. 重要剧情节点

爆发方式：
- 一日三更：冲击榜单
- 连续爆发：积累读者
- 情怀加更：感谢读者打赏
```

### 更新数据监控

**核心监控指标**：

| 指标 | 监控频率 | 健康标准 | 异常处理 |
|------|----------|----------|----------|
| 日更字数 | 每日 | ≥目标字数 | 调整时间安排 |
| 追读人数 | 每日 | 稳定或上升 | 检查内容质量 |
| 留存率 | 每周 | ≥行业均值 | 优化内容节奏 |
| 收藏增长 | 每日 | 持续增长 | 加强推广 |

**数据预警机制**：

```
数据监控预警：

⚠ 黄色预警：
- 追读下降超过10%
- 连续3天收藏增长为负
→ 建议优化内容，检查读者反馈

🔴 红色预警：
- 追读下降超过30%
- 断更超过2天
- 推荐位数据严重不达标
→ 紧急调整策略，联系编辑
```
